## 4. Пояснення Vagrantfile

У файлі Vagrantfile було задано параметри віртуальної машини та автоматизовано встановлення вебсервера Nginx.

- `Vagrant.configure("2")` — визначає версію конфігурації Vagrant.
- `config.vm.box = "generic/debian12"` — задає образ операційної системи Debian 12.
- `config.vm.hostname = "lab8-vm"` — встановлює ім'я віртуальної машини.
- `config.vm.network "forwarded_port", guest: 80, host: 8080` — перенаправляє порт 8080 основної системи на порт 80 віртуальної машини.
- `config.vm.synced_folder ".", "/vagrant"` — створює спільну папку між основною системою та віртуальною машиною.
- `config.vm.provider "virtualbox" do |vb|` — задає параметри провайдера VirtualBox.
- `vb.name = "lab8-vm"` — встановлює назву машини у VirtualBox.
- `vb.memory = 1024` — виділяє 1024 MB оперативної пам'яті.
- `vb.cpus = 1` — виділяє один процесор.
- `config.vm.provision "shell"` — запускає сценарій автоматичного налаштування.
- `apt-get update` — оновлює список пакетів.
- `apt-get install -y nginx` — встановлює вебсервер Nginx.
- `systemctl enable --now nginx` — налаштовує автоматичний запуск Nginx та запускає його.

## 6. Контрольні запитання

### Питання 1

Що таке Vagrant? Для яких завдань його використовують?

**Відповідь:**

Vagrant — це інструмент для автоматизації створення та керування віртуальними машинами. Його використовують для швидкого розгортання однакових середовищ розробки, тестування програм та налаштування серверів.

### Питання 2

Що таке Docker і чим контейнер відрізняється від віртуальної машини?

**Відповідь:**

Docker — це платформа для створення та запуску контейнерів. Контейнер використовує ядро операційної системи хоста, тому є легшим і швидше запускається. Віртуальна машина має власну операційну систему та працює через гіпервізор.

### Питання 3

Якою мовою написано Vagrant і якою мовою описується Vagrantfile?

**Відповідь:**

Vagrant написаний мовою Ruby. Файл Vagrantfile також використовує синтаксис Ruby для опису параметрів віртуальної машини.

### Питання 4

Як встановити Vagrant у вашій ОС? Які ще компоненти потрібні?

**Відповідь:**

У Windows Vagrant можна встановити за допомогою інсталятора MSI з офіційного сайту HashiCorp. Для роботи також потрібен провайдер віртуалізації, наприклад Oracle VirtualBox. Після встановлення необхідно перезавантажити комп'ютер.

### Питання 5

Який протокол використовується для підключення до гостьової системи і який порт хоста за замовчуванням?

**Відповідь:**

Для підключення до гостьової системи використовується протокол SSH. За замовчуванням Vagrant перенаправляє SSH-порт гостьової системи на порт 2222 хост-комп'ютера.

### Питання 6

Що таке box і де знайти готові образи?

**Відповідь:**

Box — це готовий образ операційної системи, який використовується для створення віртуальної машини. Готові образи можна знайти в офіційному каталозі Vagrant Cloud.

### Питання 7

Яке призначення Vagrantfile? Які параметри в ньому можна задати?

**Відповідь:**

Vagrantfile — це конфігураційний файл, у якому описуються параметри віртуальної машини. У ньому можна задати операційну систему, ім'я хоста, обсяг оперативної пам'яті, кількість процесорів, мережеві налаштування, спільні папки та автоматичне встановлення програм.

### Питання 8

У чому різниця між `vagrant halt`, `vagrant suspend` та `vagrant destroy`?

**Відповідь:**

`vagrant halt` повністю вимикає віртуальну машину. `vagrant suspend` призупиняє її роботу зі збереженням поточного стану. `vagrant destroy` видаляє віртуальну машину та пов'язані з нею віртуальні диски.

### Питання 9

Для чого `vagrant provision` та `vagrant reload`? Коли використовувати кожну?

**Відповідь:**

`vagrant provision` повторно виконує сценарії налаштування віртуальної машини, наприклад встановлює необхідні програми. `vagrant reload` перезапускає машину, щоб застосувати зміни конфігурації. Їх використовують, коли потрібно оновити програмне забезпечення або застосувати нові налаштування.

### Питання 10

Що таке synced folder і який каталог ВМ відповідає каталогу проєкту?

**Відповідь:**

Synced folder — це спільна папка між основною операційною системою та віртуальною машиною. У цій роботі папці проєкту на Windows відповідає каталог `/vagrant` у Debian.
